# Expense Tracker

A simple command-line expense tracker built with Python.

This project lets users record their daily expenses, save them into a CSV file, and load them anytime to view spending summaries. Expenses are grouped by category, and the application also calculates the total amount spent.

## Features

- Add new expenses
- Save data to a CSV file
- Load saved expenses
- Organize expenses by category
- Calculate total spending
- Simple input validation

## Categories

- Food
- Groceries
- Life Style
- Fun
- Work

## Technologies

- Python
- CSV File Storage
- Object-Oriented Programming (OOP)

## Purpose

This project was created to practice Python fundamentals, including object-oriented programming, file handling, input validation, and working with structured data.
